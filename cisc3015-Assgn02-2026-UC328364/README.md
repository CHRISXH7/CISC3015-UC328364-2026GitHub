## Opening the work

Open `.ipynb` files in Jupyter Notebook or JupyterLab. Extract a project ZIP before running its Python application. Follow the dependency and data-source instructions in the notebooks and project scripts. Where both a ZIP and an extracted project folder existed, only the ZIP is included here.

The Module 04 Lab 01 notebook is approximately 33 MB because it contains saved visualization output, exceeding the 25 MiB browser upload limit. It is provided as `.ipynb.zip`, containing the complete, unchanged original notebook. Download and extract it before opening it in Jupyter.

The map notebook is accompanied by a note about the original CARTO configuration. Some maps may need a valid map-service configuration to load again.
